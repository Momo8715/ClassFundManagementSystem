# 📒 班级班费管理系统

PHP + MySQL 的班级班费收支管理工具，支持多角色权限、缴费追踪、数据导入导出、操作审计、暗色主题。

## 快速开始

1. 上传所有文件到网站根目录
2. 访问网站，自动跳转安装向导
3. 填写数据库信息，完成部署
4. 首次安装后建议删除 `install.php`

## 功能

- 💰 收支记录管理（收入/支出、凭证上传、Excel 导出）
- 👥 多角色权限（班主任、管理员、班长、财务委员、同学）
- 📋 班级花名册 + 缴费情况追踪
- 📜 操作日志（不可删除、不可修改）
- 🛡️ 安全分析（多账号检测、异地登录告警）
- 🌗 暗色/亮色主题
- 🔄 [远程升级](UPGRADE.md)

## 系统要求

- PHP 8.0+
- MySQL 5.7+
- PDO + ZipArchive 扩展
